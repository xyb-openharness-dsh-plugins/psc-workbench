## 一、一级重名率实测

- psc 一级导航（拟定）：看板 / 化验 / 发作与缓解 / 影像复查 / 症状 / 用药 / 筛查随访 / 报告 / 设置
- pbc 一级导航（实测于其仓库）：待 M1 实测回填
- 重名率：待实测回填（预估 < 50%，两者疾病机制不同但器官同域，化验类页面名有撞形风险）

## 二、差异化矩阵（场景 / 功能 / 怎么验）

| # | 对比仓 | 场景差异 | 功能差异 | 怎么验 |
| --- | --- | --- | --- | --- |
| 1 | pbc-workbench | PSC 场景围绕胆管狭窄与胆管炎发作、IBD 共病双线随访；PBC 围绕 AMA 定性与 UDCA 应答评估 | PSC：胆管炎发作—缓解区间带 + 近 90 天发作次数（读时算不落库）；MRCP 狭窄记录字段 | 演示数据 ≥3 次发作、≥2 次 MRCP；全站无 AMA/UDCA 应答评估语义（禁词 grep 0 命中） |
| 2 | biliary-tract-workbench | PSC 为非肿瘤慢性病；胆道仓为肿瘤分期线序语义 | PSC 不出现分期/线序/疗效排序；胆管癌与结直肠癌风险仅以「医生已安排的筛查随访」口径呈现条目（MRCP、CA 19-9【待核】、肠镜） | 全站禁词扫描：分期/线序/疗效/预后 0 命中；筛查条目为随访提醒而非判读 |
| 3 | pf-ild-workbench | 胆管纤维化 vs 肺纤维化；监测对象为肝功能与影像狭窄 vs 肺功能 | PSC：肝功能指标卡按方法/机构可比组分列，不跨方法连线做差 | 指标卡含方法与机构字段；跨方法数据造数后断线不连线 |
| 4 | takayasu / anca-vasculitis | 胆管纤维化 vs 血管炎症；发作单元是胆管炎 vs 血管炎活动 | PSC：瘙痒/乏力症状随访条目化，患者语言记录，不判定级别 | 症状条目为原文引用模式，界面不生成 CTCAE 类判定词 |
| 5 | cervical-workbench（客户端链路底本） | 病种完全不同；仅移植客户端结构（src→build→lib、agent 面板、版本簿记） | PSC 语义全覆盖替换 | 移植后禁词/残留 grep 0 命中；版本十处同源 |
| 6 | breast-cancer-workbench（26 号对比基准） | 非肿瘤 vs 肿瘤；抄首页 hero、五 Tab、分类眉题、卡片与最近报告表结构 | 不抄肿瘤分期、治疗线序、疗效应答、肿瘤标志物口径 | 结构元素体系对齐清单逐项过，语义 0 残留 |

## 三、语义替换对照（非肿瘤表达替换表，节选自家族规范）

| 不能搬（肿瘤/其他病种） | PSC 对应表达 |
| --- | --- |
| D+N 天数、疗程编号折叠 | 一次发作 / 一次调药作为折叠单元 + 距上次发作 N 天 |
| 阶段标签（术后/巩固/维持） | 随访节律（稳定期 / 发作期）+ 医生原文 |
| 疗效、预后、fit 评分 | 只列医生原文与日期，不判定；阈值一律【待核】 |
| 肿瘤标志物趋势话术 | 肝功能化验（ALP/胆红素等）标注方法/单位/机构可比组 |
| 小时级轨道事件类型 | 用药 / 就诊 / 检查 / 发作开始 / 缓解开始 |

## 四、撞形风险与处置

- **DuctPal 与 pbc 小管宝撞名**：品牌占位名晨审追认时更换（DEV-PLAN §五#3）。
- **「肝功能化验」页面与 PBC 化验页撞形**：页面结构可同形，指标集合与解读口径不同（PSC 关注 ALP 与胆红素趋势、GGT；PBC 关注 ALP 应答与 AMA）——指标目录在 CLINICAL-DATA.md 单列，不引用 PBC 文档。
