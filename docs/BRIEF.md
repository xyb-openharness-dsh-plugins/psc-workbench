# 需求起点

来源：初始化配置。用户、场景和流程是有效的SPEC互动素材；继承会话中已有明确确认，其余不能仅因配置通过校验就当成设计定稿或研究验证。

目标用户：原发性硬化性胆管炎（PSC）患者及家属照护者；含合并溃疡性结肠炎/克罗恩病的共病患者、长期随访中面对瘙痒与乏力管理的成人患者；患者组织志愿者协作使用

场景：确诊依据档案（MRCP/ERCP/胆管影像与化验）与误诊经历留痕；肝功能化验周期记录（ALP、胆红素等，按方法与机构可比组分列）；胆管炎发作—缓解区间与就医经历；MRCP/FibroScan 影像复查节奏与结果；IBD 共病肠镜监测；瘙痒乏力疲劳症状记录；熊去氧胆酸等医生用药原文留档；复诊准备与移植评估材料整理（默认私密）

核心流程：
1. 选择本机资料目录并导入化验/影像/肠镜报告
2. 核对候选信息，建立确诊依据档案与随访节律
3. 记录化验结果、发作—缓解经历与症状变化
4. 整理影像复查节奏与医生用药原文
5. 生成复诊准备材料

完成结果：得到来源可追溯、可核对的个人病程档案：确诊依据、化验趋势与可比组、发作—缓解时间线、影像复查节奏与结果、症状与用药记录、复诊准备材料；所有候选信息经用户核对入档，不提供诊断与治疗建议

初始布局选择：business-first
