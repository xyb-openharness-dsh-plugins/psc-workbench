# PATIENT-FLOW · psc-workbench 患者旅程与功能线

版本：v0.1 · **0 患者访谈**：每条功能线标注证据层级；无 L1 原话，全部为 L3 推断（见 USER-RESEARCH.md）。改写句不冒充引语。

## 一、旅程阶段与功能线

| 阶段 | 患者处境 | 功能线 | 证据 | 页面落点 |
| --- | --- | --- | --- | --- |
| 确诊期 | 「PSC 是什么、为什么查了 ERCP 又要查 MRCP」 | 确诊依据档案：影像/化验/活检记录与来源，疾病概要四段 | L3 推断 · 0 访谈 | 看板 · 疾病概要（?） |
| 稳定期随访 | 每 3–6 个月抽血【待核】，想知道趋势但「不同医院结果不一样」 | 化验记录：ALP/胆红素/GGT 等，按方法+机构可比组分列，只报事实不判读 | L3 推断 · 0 访谈 | 化验 · 指标卡 |
| 稳定期随访 | 影像检查间隔长记不住 | MRCP/FibroScan 影像复查记录与「距上次 N 天」 | L3 推断 · 0 访谈 | 影像复查 |
| 发作期 | 发热寒战黄疸「要不要马上去医院」 | 发作—缓解记录 + 医生已给行动计划原文（若有）+ 求助短语【待核占位】 | L3 推断 · 0 访谈 | 发作与缓解 |
| 共病随访 | 同时跟消化科（肠镜）与肝科两套随访 | IBD 共病记录与肠镜监测条目 | L3 推断 · 0 访谈 | 筛查随访 |
| 日常 | 瘙痒乏力「天天痒但化验单上没有」 | 症状记录：患者语言原文 + 日期，不判定级别 | L3 推断 · 0 访谈 | 症状 |
| 用药 | 熊去氧胆酸等长期用药、调药记录 | 用药记录：医生医嘱原文留档，不含建议 | L3 推断 · 0 访谈 | 用药 |
| 复诊准备 | 「怕忘掉想问的问题」 | 复诊准备清单导出（看板/导出均过滤私密项） | L3 推断 · 0 访谈 | 报告 |
| 长期焦虑 | 「移植是不是早晚的事」 | 移植评估材料整理（只整理医生要求的事实材料，不评估时点） | L3 推断 · 0 访谈 | 筛查随访 |

## 二、每个阶段的一句话出口

每阶段页面页脚固定口径：「仅回顾，不解读」「解读归医生」「不同方法不合并」。
